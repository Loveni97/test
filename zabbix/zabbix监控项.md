# 一、硬件资源‌

CPU 使用率、内存占用、磁盘 I/O 与空间、网络带宽、进程数量、TCP 连接数等 ‌‌

# 二、操作系统状态‌

Linux、Windows、Unix 等主流操作系统的运行状态、服务存活情况、系统日志、防火墙状态等 ‌‌

# 三、网络设备‌

通过 ‌SNMP 协议‌ 监控交换机、路由器、防火墙、AP 等网络设备的端口状态、流量、丢包率、延迟等 ‌‌

# 四、应用程序与服务‌

支持监控 MySQL、PostgreSQL、Redis、Nginx、Apache、Tomcat、Docker、Kubernetes 等常见服务的运行状态与性能指标 ‌‌

# 五‌、Java 应用(通过 JMX)

可监控 JVM 内存、线程池、垃圾回收、类加载、运行时信息等 ‌‌

# 六‌、自定义业务指标‌

支持通过脚本、API、Zabbix Sender 或 Trapper 方式,自定义监控订单量、用户在线数、API 响应时间等业务层面指标 ‌‌

# 七‌、日志与安全事件‌

可结合日志收集工具(如 ELK)实现日志监控,并支持监控防火墙、WAF、异常登录等安全相关事件 ‌‌
